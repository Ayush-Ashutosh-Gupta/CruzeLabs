# Cruzelabs



Cruzelabs is a personal dashboard designed to centralize AI tools, notes, and lightweight utilities that are otherwise scattered across browser tabs and apps.



## Features



- AI tools deck

- Notepad

- Drawing / whiteboard space

- Simple organized workspace



## Purpose



Built to reduce tool-switching friction and keep important utilities accessible in one interface.
